## 💡 학습 원칙 (Rule)
1. **매일 1문제 이상 풀기:** 꾸준함이 가장 큰 무기입니다.
2. **코드 가독성:** 단순히 정답을 맞히는 것을 넘어, 타인이 읽기 쉬운 코드를 작성합니다.
3. **복기:** 한 번 풀었던 문제라도 더 효율적인 알고리즘(시간 복잡도 개선)이 있는지 고민합니다.
